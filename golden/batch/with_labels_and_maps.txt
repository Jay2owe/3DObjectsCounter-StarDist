3D Objects Counter - StarDist — batch output

Labels/   one 3D label image per input, objects numbered 1..N.
Objects/  one row per object per input.
Maps/     object, surface, centroid and centre-of-mass maps.
Groups/   objects and summary aggregated by the filename regex group.
Summary/  summary.csv over everything, per_folder_summary.csv by source
          folder, groups.csv by regex group, and manifest.csv.

manifest.csv records the parameters, calibration and counts for every
image. Keep it: it is what makes these numbers reproducible.

Note on method: StarDist runs on each Z-slice and the detections are
linked through Z by TrackMate. This is not a 3D StarDist model. The
Slices column reports how many slices each object spans; objects
spanning a single slice deserve a look before they are trusted.
